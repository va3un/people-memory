# Latest report
Phase 1 is built and pushed. The app is now a real, installable app with an empty data set.

What was done
- Scaffolded Vite, React and TypeScript in the repository root. Tailwind, React Router (hash mode), vite-plugin-pwa, Vitest, zod, lucide-react and sonner are added. Every version is pinned exactly.
- Added local shadcn-style building blocks: Button, Input, Sheet, Dialog, Tabs, Chip, Avatar, Card, Toast. They live as plain files in `src/components/ui/`, so nothing is downloaded at run time.
- Turned the design tokens from roadmap section 11.2 into CSS variables, with light and dark mode.
- Built the bottom bar with Search, a raised round Add button, Browse and Settings, plus the four placeholder screens.
- Built the hidden `#/design` page that shows every component for review.
- PWA: the app is called "People", installs on the phone, works offline and shows "Update ready, tap to refresh" when a new version is ready. Icons are generated by `scripts/generate-icons.mjs`, so no image tools are needed.
- Settings now shows the app version taken from `package.json`.
- GitHub Actions installs, typechecks, tests, builds and deploys to Pages on every push to `main`.

Please test
1. Open https://va3un.github.io/people-memory/ on the phone. The Search screen opens with the search box ready.
2. Tap Add in the middle of the bottom bar. The Add screen opens with a name box.
3. Tap Browse, then Settings. Each opens. Settings shows "Version 0.1.0".
4. In Chrome, open the browser menu and choose "Install app" (or "Add to Home screen"). The People icon appears on the home screen.
5. Open People from the home screen with airplane mode on. The app still opens.

Decisions I made
- `lucide-react` for the icons, `sonner` for the toast messages, `zod` for validating data later.
- Hash routing (`#/settings`), so every screen works on GitHub Pages without server settings.
- The Vite base path becomes `/people-memory/` only during the GitHub Actions build, so the same code also works on a plain computer.
- Icons are simple indigo squares drawn by a small Node script, no image software needed.
- The design page lives at `#/design`. It is not in the bottom bar, so it stays hidden.

Need from you
- None. GitHub Pages was already set to build from the Actions workflow on `main`.
